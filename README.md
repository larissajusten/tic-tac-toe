# Tic tac toe

Nome dos alunos: Larissa E. Justen

## Introdução ao projeto

Jogo tic tac toe desenvolvido em ReactTS.

#### Tema: Jogo da velha
#### Funcionalidades: Jogar (e consequentemente a possibilidade de jogar novamente)
#### Principais arquivos:
- Typescript e HMTL:
  - partida-page.tsx
- CSS:
  - partida-page.css
  - modal.css
  - iconO.css
  - iconX.css

## Como jogar

Para jogar você deve rodar o comando `npm install` no terminal que se encontra dentro da pasta do projeto.

Logo após você deve rodar `npm start` para iniciar o projeto e assim poder jogar Tic tac toe.

### Observações
Este jogo foi um refatoramento do mesmo jogo feito em 2019 quando eu estava em um acelerador de carreira numa empresa do RS.
